The payment module is fully prepared and waiting for Razorpay API keys in your server environment (.env file or Render Dashboard).

To enable checkout transactions in Test Mode or Live Mode, configure the following environment variables in your server configuration:

# Payment Gateway Configuration
PAYMENT_PROVIDER=razorpay
PAYMENT_MODE=test # or live
RAZORPAY_KEY_ID=rzp_test_...
RAZORPAY_KEY_SECRET=...
RAZORPAY_WEBHOOK_SECRET=...
